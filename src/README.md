# Core Application Source Code

This directory contains the core application source code for the Solidarity platform.

## Structure

- `api/` - REST API endpoints
- `auth/` - Authentication and authorization
- `blockchain/` - Blockchain integration
- `commerce/` - Commerce functionality
- `exchange/` - Financial exchange logic
- `models/` - Data models
- `services/` - Business logic services
- `utils/` - Utility functions
- `config/` - Configuration management

## Getting Started

1. Install dependencies: `npm install`
2. Copy environment config: `cp .env.example .env`
3. Update .env with your configuration
4. Start development server: `npm run dev`

## Technologies

- Node.js
- Express.js
- TypeScript
- JWT Authentication
- Web3 Integration

## API Endpoints

- `/api/auth` - Authentication
- `/api/users` - User management
- `/api/transactions` - Transaction handling
- `/api/exchange` - Exchange operations
