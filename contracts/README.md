# Smart Contracts

This directory contains the smart contracts and on-chain logic for the Solidarity platform.

## Structure

- `SolidarityCore.sol` - Main platform contract
- `SolidarityToken.sol` - Platform token contract  
- `SolidarityExchange.sol` - Exchange functionality
- `migrations/` - Deployment scripts
- `test/` - Contract tests

## Getting Started

1. Install dependencies: `npm install`
2. Compile contracts: `truffle compile`
3. Run tests: `truffle test`
4. Deploy: `truffle migrate`

## Technologies

- Solidity
- Truffle Framework
- OpenZeppelin Contracts
- Web3.js

## Security

All contracts should be thoroughly tested and audited before deployment to mainnet.
