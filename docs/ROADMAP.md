## Technology Stack
- **Backend:** Node.js, Express, TypeScript
- **Database:** PostgreSQL
- **Blockchain:** Ethereum, Solidity
- **Frontend:** React, Next.js
- **Mobile:** React Native
- **Cloud:** AWS/Azure
- **Security:** JWT, OAuth2, Multi-factor auth
