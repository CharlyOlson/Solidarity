# Color Palettes and Design Tokens

This directory contains the design system for the Solidarity platform.

## Structure

- `colors.json` - Color palette definitions
- `typography.json` - Font and text styling
- `spacing.json` - Spacing and layout tokens
- `themes/` - Theme variations
- `components/` - Component-specific styling

## Design Philosophy

The Solidarity platform emphasizes:
- **Trust** - Professional, secure feeling
- **Community** - Warm, welcoming colors
- **Innovation** - Modern, forward-thinking design
- **Accessibility** - High contrast, readable text

## Color Palette

### Primary Colors
- Solidarity Blue: `#1B4D8C` - Trust, security
- Community Green: `#2E7D32` - Growth, prosperity
- Innovation Orange: `#FF6F00` - Energy, creativity

### Secondary Colors
- Light Gray: `#F5F5F5` - Background, neutral
- Dark Gray: `#212121` - Text, content
- Accent Gold: `#FFD700` - Highlights, success

### Status Colors
- Success: `#4CAF50`
- Warning: `#FF9800` 
- Error: `#F44336`
- Info: `#2196F3`

## Usage Guidelines

- Use primary colors for branding and main actions
- Secondary colors for backgrounds and supporting content
- Status colors for feedback and notifications
- Maintain WCAG AA accessibility standards
